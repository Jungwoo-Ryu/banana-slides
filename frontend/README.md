# Sol.A React frontend

Use Node.js 22.23.4. Run `npm ci`, then `npm run dev` with the Go backend. The root `start-web.bat` / `start-web.sh` starts both. `npm run build:wails` embeds this same UI in the Windows app.

Backend code and test fixtures live in ../backend. Follow the [root setup guide](../README.md) and [browser tests](e2e/README.md).

## Local web

Install Node.js 22.23.4 and uv, then check out the maintained fork:

```bash
git clone --branch Dev https://github.com/Jungwoo-Ryu/banana-slides.git
cd banana-slides
cp .env.example .env
```

Configure company Azure deployments in `.env` as described in [Configuration](/configuration). On Windows, run `start.bat`. On Linux/macOS:

```bash
uv sync --frozen --python 3.12
uv run python scripts/start_local.py
```

Open http://127.0.0.1:3011. The backend uses port 5011. Stop both services with Ctrl+C in the launcher terminal. OCR needs local Tesseract with Korean/English language data; video export needs FFmpeg/FFprobe and a separate Azure TTS deployment.

## Containers

Build the checked-out fork instead of pulling an upstream application image:

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

Back up the database and uploads together before upgrading. The migration moves legacy parsed artifacts to `parsed_files` and rewrites saved local links. Conflicting destination directories stop the migration without overwriting files. Keep persistent database/uploads volumes mounted.

## Logs

Local launcher logs are under `.runtime/logs/`. Container logs:

```bash
docker compose -f docker-compose.prod.yml logs --tail 100 backend
```

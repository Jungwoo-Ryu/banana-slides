## Azure Foundry OpenAI

Sol.A uses company-managed Azure deployments for text, vision, image generation/editing, and speech. Configure server environment variables or mounted secrets; the browser cannot store provider credentials.

```env
AZURE_OPENAI_ENDPOINT=https://YOUR-RESOURCE.openai.azure.com
AZURE_OPENAI_API_KEY=
AZURE_OPENAI_API_VERSION=v1
AZURE_OPENAI_DEPLOYMENT=gpt-5.5
AZURE_OPENAI_IMAGE_DEPLOYMENT=gpt-image-2
AZURE_OPENAI_CAPTION_DEPLOYMENT=
AZURE_OPENAI_TTS_DEPLOYMENT=
AZURE_OPENAI_TTS_VOICE=alloy
```

Use actual Azure deployment names. An empty caption deployment uses the text deployment. Video narration requires a separate Azure TTS deployment plus FFmpeg/FFprobe. Configure HTTPS with the company CA when necessary; TLS verification stays enabled.

## Local documents and OCR

```env
DOCUMENT_PARSER=local
OCR_PROVIDER=local
OCR_LANGUAGES=kor+eng
TESSERACT_CMD=
INPAINTING_PROVIDER=local
TEXT_STYLE_PROVIDER=local
```

PyMuPDF extracts PDF text locally. MarkItDown handles supported Office documents with plugins disabled. Tesseract handles scanned pages and editable text extraction; install the executable and the relevant language data. PDF templates with a text layer do not require a separately hosted OCR model. Local OpenCV restores backgrounds for editable exports. Generative background restoration uses the configured Azure image deployment.

External document/OCR upload adapters are removed. Non-local parser/OCR selections are rejected rather than silently redirected. There is no automatic segmentation-model download.

## Performance and design

Start with `MAX_IMAGE_WORKERS=1` on a 1-core/2-GB backend. The web Settings page controls generation concurrency, text output limits, image quality, output language, and a reusable design-system prompt. The supported environment defaults are documented in `.env.example`.

Provider credentials and deployment names remain server-managed. Restart the backend after changing environment configuration. Saved UI preferences take precedence over their environment defaults.

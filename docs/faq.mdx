## When is OCR needed?

Scanned PDFs and extracting editable text from slide images need OCR. Install local Tesseract and the selected language packs. Text-layer PDFs can be parsed without OCR. Generating a slide image from an outline does not require OCR.

## Editable PPTX has incorrect text or layout

Check the OCR health test and installed languages. OCR reconstruction can differ from the source image, especially for complex charts and tables. Regular PPTX export embeds the slide image and preserves its appearance; text inside it is not editable.

## Image generation fails

Verify the Azure image deployment, permissions, quota, and request diagnostics in the backend log. A working text deployment does not establish image deployment availability. Reduce parallel image workers to one on small containers. Do not switch to an external relay service.

## Video export fails

Video export needs an Azure OpenAI TTS deployment and FFmpeg/FFprobe. GPT-5.5 and GPT-image-2 alone do not provide speech. Review each slide's narration script before exporting.

## Template upload fails

Use PDF for predictable rendering. PPTX conversion may require LibreOffice and compatible fonts. Scanned documents also need local OCR. Parser/OCR settings must both be `local`; remote upload adapters are no longer supported.

## Environment changes are not taking effect

Restart the backend after editing its environment. Saved UI preferences override environment defaults for those preferences. Azure credentials remain server-side.

## How can I edit just one region?

Open the slide editor and drag on the image. Move or resize the selected region, adjust its original-pixel coordinates, and enter an edit instruction. Submit to regenerate using the configured Azure image deployment.

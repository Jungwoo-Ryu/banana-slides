## Incremental rule

- `docs/i18n/readme-state.json` Saves the last successfully synchronized Chinese original and SHA-256。Compared to that state, not with the workspace `HEAD` Compared, thus allowing for cumulative multiple submissions and changes after previous failures。
- The unchanged sections directly retain the original text in the target document, including manual colouring. The revised sections hand over the old Chinese, the new Chinese and the current translation to the model, updating only the corresponding chapter; the new sections generate translations, remove and move chapters to restructure directly。
- The model gets a protected placeholder. The code block (including a comment in Chinese), the line code、URL and HTML Restore label as it is; check placeholders, code fences、HTML Order and Title Level。Hero Language selection status and button material is generated from the list and does not give the model guess。
- Naked. URL Keep spaces separated from post-translation assistive words, markers, and avoid spelling them into linked addresses in languages such as Korean；Markdown Linked target does not insert spaces。
- It’s the same. Hero The navigation change only updates the interface and does not trigger the translation of the body. The new language generates the entire translation for the first time, followed by an incremental synchronization。
- Every request is tried at the most. 3 Number of times, single HTTP Timeout 120 Seconds, maximum 4 Send a request side by side. Successful sections cache to be Git Ignored `.cache/readme-i18n/`，Run again after failure; Cache is not synchronized。
